# Public data download and layout

The repository contains no raw or processed competition data. Accept the data
provider terms and download from the official competition pages:

- M5 Forecasting Accuracy: <https://www.kaggle.com/competitions/m5-forecasting-accuracy/data>
- Corporación Favorita Grocery Sales Forecasting: <https://www.kaggle.com/competitions/favorita-grocery-sales-forecasting/data>
- Store Item Demand Forecasting Challenge: <https://www.kaggle.com/competitions/demand-forecasting-kernels-only/data>

Place extracted files under:

```text
data/raw/m5/
data/raw/favorita/
data/raw/store_item/
```

Minimum files checked by the current validation-demand preparer are:

| Data set | Files |
|---|---|
| M5 | `calendar.csv`, `sales_train_evaluation.csv` |
| Favorita | `train.csv`, `items.csv`, `stores.csv`, `holidays_events.csv` |
| Store Item | `train.csv` |

The historical neural feature pipeline additionally consumed M5
`sell_prices.csv` and Favorita `oil.csv` and `transactions.csv` (alongside
calendar, promotion, and event fields). These are not yet regenerated by the
public demand-only preparer. The table above is therefore not a complete
neural-training input list.

Store Item `test.csv` and `sample_submission.csv` are outside the permitted
information set. The preparation command never opens them, even if they are in
the raw directory.

The three data-preparation commands use the locked 90-node ordering. The
Favorita and Store Item item-store maps are in `configs/v1/locked_nodes/` and
were extracted from the original final-sample records; no new sample is chosen.
The commands reconstruct validation-period demand panels, not the full
historical 17-feature neural tensors. Neural training remains separately
blocked until that exact feature interface and model source are portable.
