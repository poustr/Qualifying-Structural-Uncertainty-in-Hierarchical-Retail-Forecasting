# Full 639-task reproduction

The formal manifest, rather than a hard-coded count in the runner, is the
source of the 639 tasks. Inspect it without starting training:

```bash
python scripts/run_unified_rerun_v1.py --config configs/v1/full_unified_training_v1.yaml --data-root data/derived --output-root outputs/full_unified_run_v1 --resume --dry-run --summary-only
```

Useful filters are:

```bash
python scripts/run_unified_rerun_v1.py --dataset m5 --stage 1 --dry-run
python scripts/run_unified_rerun_v1.py --task-id v1_0001_m5_20151207_seasonal_naive_s13 --dry-run
python scripts/run_unified_rerun_v1.py --dataset favorita --max-tasks 5 --dry-run
```

`--resume` skips a task only when its own `completed.json` exists. A failed
subprocess remains visible and stops the coordinator; no empty or zero forecast
is created.

No 639-task run was launched while preparing this release. Full execution is
currently blocked by unverified non-no-graph model families and third-party
revisions or license constraints. The exact Controlled TCN source, 90-node
raw-ID maps, validation-demand panels, and all three data sets' 42 historical
neural tensors and three business graphs have been recovered and hash-checked.
The no-graph Controlled TCN path has passed one real M5 task, checkpoint
reload, and resume. These remaining blockers do
not affect the quick numerical reproduction.

Remaining work is model-specific rather than another general data-preparation
pass: the statistical TCN requires the original pre-experiment structure
tables (the adapter path is now configurable); M5/Favorita semantic inputs
can now be regenerated by `scripts/prepare_v1_semantic_embeddings.py`
with hashes matching the historical tensors, but their real training tasks
have not yet been checked. Modern and adaptive models require their pinned
external revisions and real single-task checks. MixLinear and MAGE have no
recorded upstream license file, so their source is neither bundled nor
automatically installed. A 639-task dry-run is not a 639-task retraining test.
The statistical adapter's path-only correction passed no-gradient forward
checks on M5, Favorita, and Store Item using synthetic targets and the
read-only original structure tables. For a local reproduction, place the
three original structure tables under `data/derived/structure_inputs/outputs/`
with their original relative paths, or set `RETAIL_STRUCTURE_ROOT` to the
directory containing `outputs/`. This is an input-path rule, not a substitute
for a reader-side structure-estimation pipeline.

Only after each remaining model-family adapter has passed real single-task
and resume checks should readers omit `--dry-run` for the full manifest. The
present coordinator is a verified task dispatcher, not a verified 639-task
retraining implementation. When all tasks complete, run
`python scripts/reproduce_paper_results.py` against exported task-level inputs
to regenerate the published results.
